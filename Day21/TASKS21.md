# 📅 Sunday (Day 14) – Review & Consolidation  
**100 Days AI/ML Challenge**

---

## 🎯 Goal of the Day
To strengthen fundamentals, review progress from the past week, identify gaps, and plan effectively for the upcoming week. This day focuses on **revision, reflection, and preparation**, not learning new heavy concepts.

---

## ⏰ Time Allocation (4 Hours Total)

### ✅ 1. Quiz (1 Hour): Python & Pandas Fundamentals

**Python Topics**
- Variables and data types  
- Conditional statements  
- Loops (`for`, `while`)  
- Functions  
- Lists, tuples, sets, dictionaries  
- List comprehensions  

**Pandas Topics**
- `Series` and `DataFrame`
- `read_csv()`
- `head()`, `tail()`, `info()`, `describe()`
- Indexing with `loc` and `iloc`
- Handling missing values (`isnull()`, `fillna()`, `dropna()`)

📌 **Goal:** Identify weak areas, not score perfection.

---

### ✅ 2. Code Review (1 Hour): Review Week’s Work

- Revisit notebooks and scripts from the past week
- Check for:
  - Repeated or redundant code
  - Unclear variable names
  - Long, unstructured cells
  - Missing comments or explanations

🔧 **Optimization Tasks**
- Convert repeated logic into functions
- Improve variable naming
- Add brief comments where needed
- Remove unnecessary print/debug statements

### ✅ 3. Planning (1 Hour): Plan for Next Week

- Reflect on:
  - Topics you found difficult
  - Topics you felt confident in
  - Concepts that need more practice

🗓️ **Create a plan for next week**
- Weekly learning goal
- Daily topic breakdown
- One mini-project or practice task
- One revision or buffer day

Write the plan in notes, Notion, or a markdown file.

### ✅ 4. Stretch (1 Hour): Explore Advanced Pandas Topics

Explore (not master) **any 2–3 topics**:
- `apply()`, `map()`, `applymap()`

- `pivot_table()`
- `merge()` vs `join()`
- Rolling & expanding windows
- `pd.cut()` and `pd.qcut()`

🎯 **Goal:** Awareness and exposure, not memorization.
